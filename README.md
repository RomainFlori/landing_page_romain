⚡ Quick Start
1. Installation
Bash
npm install
# ou yarn, pnpm, bun
2. Développement
Bash
npm run dev
Accès local : http://localhost:3000

/app: Routes, layouts et composants (App Router).

/public: Assets statiques.

Dockerfile: Configuration de la containerisation pour GCP.
